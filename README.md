# 🏡 WonderLust – Property Rental Platform

WonderLust is a full-stack property rental web application inspired by Airbnb. It allows users to explore rental listings, create accounts, add new properties, upload images, leave reviews, and manage listings through a clean and responsive interface.

---

## ✨ Features

* 🔐 User Authentication (Sign Up / Login / Logout)
* 🏠 Browse property listings
* ➕ Add new rental listings
* ✏️ Edit and delete your own listings
* ⭐ Leave ratings and reviews
* 🖼️ Upload property images using Cloudinary
* 📍 View property locations with interactive maps
* 📱 Responsive user interface
* 🛡️ Secure session management and authorization

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/wanderlust.git
```

### Navigate to the project

```bash
cd wanderlust
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
MONGO_URL=your_mongodb_connection_string

CLOUD_NAME=your_cloudinary_cloud_name
CLOUD_API_KEY=your_cloudinary_api_key
CLOUD_API_SECRET=your_cloudinary_api_secret

SECRET=your_session_secret
MAP_API_KEY=your_map_api_key
```

### Start the application

```bash
npm start
```

or

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:8080
```
